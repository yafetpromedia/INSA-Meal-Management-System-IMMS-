# IMMS Frontend Architecture

Full specification: [SRS Part 7](../srs/07-frontend-architecture-and-ui-ux.md) (includes **7.28–7.41** premium SaaS design philosophy).

| Item | Value |
| ---- | ----- |
| App | `apps/meal-web` |
| Aesthetic | Premium enterprise SaaS (Linear / Stripe / Vercel–inspired), not a generic admin template |
| Accent | Orange used sparingly |
| Neutrals | Majority of surfaces |
| Icons | Lucide (outline) |
| Spacing | 8px grid |
| Motion | 150–250ms, subtle |
| Critical UX | `/meals` scanner station |

## Design instruction

Do not use generic admin dashboard templates or “vibe-coded” UI patterns. Prioritize usability, whitespace, typography, subtle animation, and focused meal workflows over decoration.
